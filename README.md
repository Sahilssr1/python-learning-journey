## 📌 About The Project

Welcome to my **Python Learning Journey**! This repository serves as a centralized digital lab and revision notebook where every core Python concept is explored through:

- **Isolated Code Demonstrations**: Clean, focused scripts demonstrating single principles.
- **In-depth Practice Sets**: Real algorithmic challenges, mathematical queries, and logic puzzles.
- **Standard Library & Third-Party Exploration**: Hands-on experimentation with modules like `os`, `sys`, `pyttsx3`, `pyjokes`, and more.

Whether you're starting your own Python journey or looking for concise reference snippets, feel free to explore, clone, and build upon this code!

## 🚀 Getting Started

Follow these steps to run any script locally on your machine:

### 1. Prerequisites
Ensure you have **Python 3.10+** installed. Check your version with:
```bash
python --version
```

### 2. Clone the Repository
```bash
git clone https://github.com/Sahilssr1/python-learning-journey.git
cd python-learning-journey
```

### 3. Optional: Install Required External Libraries
Certain chapters experiment with community packages (`pyttsx3`, `pyjokes`):
```bash
pip install pyttsx3 pyjokes
```

### 4. Run Any Script
Execute any file directly using Python:
```bash
# Example: Run prime checker and star patterns from Chapter 7
python chapter7/08_practice_set.py

# Example: Run dictionary exercises from Chapter 5
python chapter5/06_Practice_question.py
```
